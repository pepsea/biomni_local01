# 29. 実行中の画面

## 停止ボタンが勝手に消える

```js
es.onerror = () => finish();
```

`EventSource` は接続が切れると**自分で繋ぎ直します**。`onerror` はその
再接続の途中でも呼ばれます。つまり「一瞬切れた」だけで `finish()` が走り、

- 停止ボタンが消える
- ストリームを `close()` してしまうので、以後の進行も届かない

一方、**ランはブラウザではなくサーバで動いています**。接続が切れただけで
止まったわけではありません。画面だけが終わったつもりになっていました。

### 直し方

`readyState` で分けます。

```js
es.onerror = () => {
  if (es && es.readyState === EventSource.CONNECTING) {
    connNote("接続が切れました。再接続しています…");
    return;                    // ブラウザに任せる
  }
  reconcile(id);               // 本当に閉じた。勝手に終わったことにしない
};
```

`reconcile()` は `/api/runs/<id>` を見て、`running` ならつなぎ直し、
停止ボタンも出したままにします。終わっていれば結果を描いて片付けます。

サーバ側は元から正しくできていました。全イベントに `id:` を振り、
15 秒ごとに keep-alive を送り、再接続時は `last-event-id` から流し直します。
壊れていたのはクライアントの後始末だけです。

### 確認

イベントを 1 つ返して必ず切れるストリームを差し込み、実ブラウザで比べました。

```
直す前  : 切断後の停止ボタン = none
直した後: 切断後の停止ボタン = block
```

## プロンプトを確認すると元に戻れない

「プロンプトを確認」は実行トレースの中身を**置き換えて**いました。戻す手段が
無いので、調査中に押すと進行表示が消えたまま戻りません。

ドロワーに出すようにしました。`×` か外側のクリックで元の画面に戻ります。

ひとつ注意があります。ドロワーは `document` のクリック監視で閉じるので、
ボタンから開くときは `stopPropagation()` しないと、**開いたクリックが
そのまま閉じてしまいます**。`openDrawer()` に寄せ、呼び出し側で止めています。

## 停止の置き場所と履歴リンク

- 停止は左パネルの末尾にありました。フォームが長いので、ラン中に表示されても
  画面外です。実行トレースと同じ行の右端に移しました。
  `#tabs` の子にはしないこと。`showTab` は `$("tabs").children` を走査し
  `onclick` は `dataset.tab` を見るので、中に入れると押した瞬間に
  `showTab(undefined)` になってタブの中身が全部消えます。
- 調査履歴は左下に固定し、別タブで開くようにしました。調べている最中に
  同じタブで開くと、進行中の画面を失います。

いずれも構造をテストで縛っています。

## 使っていない方式のエラーで止まる

```
✗ Docker デーモンに接続できません
```

Docker を使わない構成なのに、更新のたびにこれが出ていました。
原因は案内のほうです。常駐のさせ方が 3 通り（systemd ユーザー / launchd /
Docker）あるのに、更新の手順として `make docker-rebuild` を書いていました。

`bash scripts/update.sh`（`make update`）を足しました。

1. `git pull --ff-only`
2. **動いているものを探す** — systemd（ユーザー / システム）、launchd、
   Docker の順に見て、動いている方式だけを入れ替える。
   どれも動いていなければ、Docker のエラーではなく
   「常駐していません」と言い、`start.sh` と `install-local-service.sh` を出す。
3. `/api/health` を叩き、**ビルド ID が手元の HEAD と一致するか**まで見る。
   一致しなければ古いプロセスが残っている。この確認が無かったので、
   「pull したのに変わらない」を何度も往復した。

README と INSTALL の更新手順も `make update` に統一しました。
